# Согласованные требования, 27.10.2026

## Порядок установки

1. Запуск CLI.
2. Выбор нативного режима либо браузерного моста с ПК.
3. SSH/root, модель Plum, ABI, место и компоненты выбранного режима.
4. Проверка внешнего IP и страны: колонка для native, Linux-ПК для bridge. RU требует VPN; другая определённая страна проходит.
5. Настройка режима, вход в собственный аккаунт ChatGPT.
6. VLESS, автозапуск, фразы после «Алиса», цвет и анимация.
7. Проверенный пакет, установка, запуск и проверка настоящего ответа.

## Согласовано

- Root/SSH уже должны быть настроены.
- Существующий мост через браузер ChatGPT сохраняется.
- На колонке остаётся нативный WebRTC/NetEq, ПК после установки не нужен.
- VLESS: одиночная ссылка и подписка; при отказе запретить прямой выход, закрыть GPT и вернуть Алису.
- Раздельные конфигурации и меню режимов, исключительное владение аудио.
- Управление после установки: start/stop/status, login/logout, autostart enable/disable, VPN start/stop/status, перенастройка фраз и LED.
- Первая установка запускает единый мастер автоматически. Управление после установки — отдельные экраны с сохранением подменю и выбранного пункта.
- В мастере подключение, автозапуск, фразы и подсветка предлагаются последовательно. Сохранённый VLESS можно оставить без повторного ввода. В управлении команды без ввода обновляют результат без закрытия экрана.
- Перед записью показывается размер выбранного пакета, доступное место и пиковый запас для обновления. Есть удаление программных файлов с сохранением SSH и аккаунтов.
- На ПК автозапуск привязывается к пользовательской сессии; на колонке — к загрузке устройства.
- Российский внешний IP даёт «Требуется VPN», другая определённая страна — «Пройдена». Здесь не проверяются HTTP ChatGPT и голос. Отдельный тест голоса доступен после входа.
- Лимит, потеря сети и недействительный вход не должны оставлять аудиофокус/TTS/LED занятыми и не вызывают бесконечных повторов.
- Живые аккаунты: Free и Plus. Go проверяется fixtures, живой результат помечается как не проверенный.
- Публичная версия объединяет оба режима в одном установщике.

## Первый этап Linux

- Переносимый установщик для Linux x86_64.
- Оба движка копируются без private state и без всей папки исследований.
- CLI использует готовые ARM-артефакты с manifest SHA-256 и проверкой ABI, без компиляции на компьютере обычного пользователя.
- Цветное меню: стрелки/Enter; автозапуск переключается прямо в общих настройках через Enter/Пробел. Главный экран сокращён до шести строк; фразы, подсветка, голос и автозапуск собраны вместе, техническое обслуживание вынесено отдельно. Сведения о выделенном пункте подгружаются автоматически с задержкой и кэшем; действия требуют Enter. Esc отменяет текущий диалог. Подсветка показывает демо на колонке при выделении, с восстановлением при отмене. Мастер явно запрашивает IP, порт, пользователя и скрытый пароль; сетевого поиска нет.
- SSH из мастера использует явные параметры и собственный known_hosts; пароль однократно передаётся OpenSSH через приватный канал askpass, после чего сохраняется отдельный ключ. Пароля нет в файлах, аргументах и переменных окружения. В командном режиме остаётся поддержка пользовательского alias.
- Аккаунт импортируется из отдельного браузерного профиля; смена аккаунта архивирует его настройки отдельно.
- Настройки фраз экспортируются в контроллер колонки; произвольные shell-команды не исполняются.
- Нативный VPN должен охватывать HTTPS и UDP/WebRTC того же процесса, а не только запросы к chatgpt.com.

## Проверка Windows

На Linux найдены QEMU, libvirt, Wine и доступный `/dev/kvm`. Переключаться на Windows прямо сейчас не нужно. Общие модули и упаковка проверяются на Linux, Windows-процессы/автозапуск — в Windows VM при наличии образа. Реальную работу браузерного аудиомоста и запуск после входа пользователя необходимо затем проверить в Windows, предпочтительно на пользовательском ПК.
